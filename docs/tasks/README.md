# Task lists, one file per chat

Each chat Navid opens gets its own branch and its own file here (`docs/tasks/<chat-name>.md`), so two chats never edit the same file and never conflict.

- Every screenshot or message Navid sends in that chat becomes a row.
- When Navid says "finished", the chat opens one PR and shows this table with what is **Done** and what is **Pending**.
- Status: **Pending** (not started or not finished), **Done** (fixed and tested here), **Check live** (fixed, needs one look on the live site after deploy).
